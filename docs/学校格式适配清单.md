# 学校格式适配清单

目前仍按已确认的通用计算机本科毕设结构交付。学校模板、个人信息和正式提交规则尚未提供，不能把通用排版标成学校格式已通过。

| 需要确认的材料 | 当前状态 | 收到后处理 |
| --- | --- | --- |
| 学校论文 Word 模板及示例 | 尚未提供 | 应用真实纸张、页边距、标题层级、字体及目录规则 |
| 字数、章节和参考文献要求 | 尚未提供 | 按学校实际口径统计，调整正文与引用格式 |
| 学校、学院、班级、姓名、学号、指导教师 | 未编填 | 仅按本人确认的信息填写封面 |
| 原创声明、授权书及签字页 | 尚未提供 | 使用学校原表，签名由本人及有关教师完成 |
| 答辩时长与 PPT 模板 | 尚未提供 | 将通用汇报稿适配真实页数、时长和版式 |
| 提交格式与文件命名 | 尚未提供 | 根据通知导出 Word/PDF、源码和演示材料 |

内容验收已经与版式分开记录。真实模型实验保留失败、未知消耗和原始分数；人工备用卡片不作为模型输出。后续格式适配不会改变实验数据或把尚未完成的浏览器验收标成通过。

论文当前提供可编辑 Word、Markdown 及图源。学校模板到位后，在副本上应用样式，再检查目录、图表编号、分页、参考文献和导出 PDF；保留已验收版本作为对照。
