# 固定评价与论文交付实现计划

> 面向工作代理：以独立职责任务执行，先规格复核，再质量复核；当前目录无 Git。用户已授权执行，使用本机隔离目录，不改写正式数据。

**目标：** 在既有系统上补齐可复现评价工具、真实统计、完整通用论文初稿和验收证据。

**架构：** `experiments/` 提供固定数据、隔离项目装载、三组模型适配、统一评分和结果汇总；复用生产 `ProjectTools/check_plan/AgentOutput`，不为评价修改生产 Agent。`docs/thesis/` 保存技术正文与引用，实验完成后导入实际汇总。验收使用独立库，浏览器以正式受信任入口为唯一自动操作入口。

**技术栈：** 现有 Python 环境、现有 OpenAI 兼容 SDK、pytest、JSON/CSV、Markdown；文档与绘图使用内置工作区依赖。

## 任务 1 固定评价框架

文件职责：`experiments/fixtures.py` 隔离状态；`cases.json` 输入和预标注；`scoring.py` 统一评分；`runner.py` 三组调用和脱敏日志；`reporting.py` 统计；`tests/` 可执行行为测试；`README.md` 复现与指标定义。

- [ ] 先写评分测试：空输出不能在要求计划的样例获得成功；缺失用量为 null；无效输出和网络失败进入分母；不同成员、日期、工时不可匹配为正确；保留已完成任务约束；日期与初始状态固定。
- [ ] 实现 3 个开发样例及 10 个评价样例，覆盖明确任务、信息缺失、更正、依赖时间、容量、需求覆盖、循环、不可行、完成保护和延期传播；评价标签不得提供给模型。
- [ ] 三组使用相同结构协议；聊天组提供统一名称/编号翻译目录以避免仅因无法映射编号而失败；上下文组和 Agent 使用同一项目状态。差异和预算写入记录。
- [ ] pytest 先失败再通过；先 dry-run，不调用网络。
- [ ] 独立审查通过后冻结数据与协议哈希，评价两次重复，最多 180 次外部模型请求，免费价格或额度不满足则保留明确未完成状态。
- [ ] 真实结果生成逐条 JSON、CSV、方法汇总、图表和失败案例索引。

运行：`D:\Anaconda3\envs\face_env\python.exe -m pytest experiments/tests -q`。预期：可重复、无真实网络调用，所有行为测试通过。
