# Stitch 界面改造源码审查记录

日期：2026-10-13。范围：已授权的 Vue 界面改造，不包含新版真实浏览器验收、模型质量实验或论文验收。

独立审查先核对实现计划、需求与设计规范，再检查代码质量。公共导航、主题、抽屉已在前一轮规格和质量复验通过；本轮重点检查工作台、团队协作、任务、计划比较、阶段审核及实时刷新边界。所有复现使用受控内存渲染和测试数据，未改写正式演示数据。

| 问题 | 复现与影响 | 修复及复验 |
| --- | --- | --- |
| P2：计划比较缺少真实差异值 | 仅改说明或验收条件时虽显示“调整”，前后值不可见 | 对实际变化的任务名、说明、需求、验收、阶段、成果和阻碍分别展示前后值；2 项回归先失败后通过；独立规格复验 PASS |
| P1：任务刷新后误提交旧字段 | 工作台抽屉编辑进度期间，团队更新日期、工时、依赖；保存会把旧表单值误认为修改并回填 | 独立保留表单打开时的比较快照，依赖数组分别克隆；只读依据和权限用最新任务，完成纠正原因用当前状态；2 项回归先失败后通过；独立规格和质量复验 PASS |
| P2：迟到发送响应清空新草稿 | 第一条消息等待响应期间继续输入第二条及关联，第一条返回时新输入消失 | 保存本次 payload 后清空本次输入，等待返回仅复位发送状态；原 outbox 保留消息及失败重试；1 项延迟响应回归先失败后通过；独立质量复验 PASS |
