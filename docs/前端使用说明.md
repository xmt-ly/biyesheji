# 前端使用说明

课协前端使用 Vue 3.5.43、JavaScript 和 Vite 8.3.4，无额外路由或 UI 框架。界面提供中文学生工作区和教师工作台，所有课程、项目、消息、草案、任务、版本、附件和审核数据来自后端 API。演示账号提示是公开初始化信息，界面不会生成模拟分析结果。

## 启动与构建

在 `D:\DevelopTools\biyesheji\frontend` 运行：

```powershell
& 'D:\nodejs\npm.cmd' install --cache 'D:\DevelopTools\biyesheji\work\.npm-cache'
& 'D:\nodejs\npm.cmd' run dev --cache 'D:\DevelopTools\biyesheji\work\.npm-cache'
```

开发入口为 `http://127.0.0.1:5173`。后端需在 `127.0.0.1:8000` 运行。Vite 将 `/api` 的 HTTP 与 WebSocket 请求代理至后端；前端不会读取或要求输入模型凭据。

```powershell
& 'D:\nodejs\npm.cmd' test --cache 'D:\DevelopTools\biyesheji\work\.npm-cache'
& 'D:\nodejs\npm.cmd' run build --cache 'D:\DevelopTools\biyesheji\work\.npm-cache'
```

构建输出为 `frontend/dist`。后端检测到该目录后提供根路径页面与 assets，同源生产入口为 `http://127.0.0.1:8000`。`vite preview` 只预览构建，不代替带 API 的后端；完整生产演示使用后端入口。后端启动和显式初始化演示数据步骤见项目部署说明与 `docs/API.md`。

## 登录与演示账号

初始化后可使用 `teacher`、`leader`、`member1`、`member2`、`leader2`、`member3`，统一演示密码 `Demo2026!`。登录页面点击账号只填入公开账号信息，仍需提交登录表单并由服务端验证。

登录令牌保存在当前标签页的 `sessionStorage`。退出会清理登录、项目数据、错误提示及实时连接。当前身份的 401 会统一退出，旧身份迟到的 401 不清除新会话。教师身份来自 `/auth/me`，学生组长或成员权限来自当前项目返回的 `role`；在另一个项目担任组长不会获得当前项目的组长入口。

## 学生操作路径

新版工作台在选中项目后展示“我的下一步”和本人任务，其他成员的未完成任务放在“协同关注”中，不计入本人数量。阻碍和规划风险优先提示；已完成任务不再作为下一步。待核对数量依据卡片实际状态，阶段提醒依据各阶段最新提交。点击本人任务可直接打开任务抽屉。

1. 从项目工作台进入已加入项目。学生可选择已发布课程创建新项目，并自动成为组长。加入现有项目需由组长在“团队成员”中使用准确用户名邀请；初版没有自行加入入口。
2. 在“团队成员”填写本人技能（每行一项）和每周可投入小时数。其他成员容量用于规划检查，成员仅能修改本人的资料。队友进度或卡片更新触发刷新时，尚未保存的资料输入会保留；保存成功后显示服务端接受的结果。
3. 在“课程要求”查看课程说明、验收标准、功能要求、三个检查阶段和已发布版本历史。在“需求清单”提出细化需求、关联课程功能并填写验收条件；组长确认需求，普通成员可修改本人尚未确认的建议。
4. 在“团队协作”发送讨论。可关联任务、需求或卡片；Ctrl + Enter 发送。消息通过 HTTP 持久化，WebSocket 提供实时更新。失败消息保留发送标识，点击“重试发送”复用同一标识。WebSocket 或历史补漏确认同一消息已经持久化后，会移除待发副本；即使 HTTP 回复中断，也不会重复显示“发送失败”。断线后自动重连并按 200 条分页补齐历史。
5. 展开“请求智能分析”，选择“讨论整理与追问”“生成初始计划”或“分析计划调整”请求真实分析；模型配置完成后，讨论与业务变更还会自动触发持续分析和主动追问，人工按钮用于重试或专门规划。模型未配置或供应商调用失败时显示服务端错误，人工聊天与业务操作继续可用。配置就绪仅表示字段齐全，实际调用仍可能失败。
6. 在分析与计划草案中查看来源消息、未解决问题、任务建议、实时约束结果及反馈记录。“回复追问”关联卡片；“更正建议”还明确使旧建议失效。来源按钮定位实际聊天记录。
7. 无模型时使用“人工草案”。可加入现有未完成任务，或通过完整任务表单新增任务；每项保留关联需求、负责人、工时、阶段、日期和依赖。人工草案始终有明确标记。草案是变更列表，未列出的现有任务不会被删除。
8. 成员反馈核对并可编辑草案。编辑会让旧确认失效；过期草案需要填写重新核对原因。存在未解决问题、无任务、约束失败、基础修订过期或已发布等状态时不能直接发布。组长查看团队反馈并勾选“已查看成员反馈并确认分工与排期”后发布，服务端再次检查并保存新计划。
9. 在“任务看板”点击任务，右侧抽屉同时显示说明、需求、验收条件、日期、前置任务及操作表单。成员推进本人未完成任务的状态、进度、剩余工时、成果和阻碍；组长维护规划字段。已完成任务的纠正必须由组长填写原因。创建或规划调整接受服务端约束校验；保存只提交相对打开表单时实际编辑的字段，团队刷新不会使未编辑的旧排期随进度回填。只读任务依据仍展示最新记录。
10. 任务详情可添加评论、阻碍或成果记录，并上传附件关联任务成果。协作评论不自动覆盖任务 blocker 或 artifact_url，需要在任务表单中保存相应字段。所有成果链接仅允许 http、https 或合法的 `/api/files/<id>` 附件路径。
11. 在“计划与排期”选择两个真实版本比较负责人、日期、工时、依赖、状态与任务增删。任务名称、说明、需求、验收条件、阶段、成果或阻碍有变化时，前后列显示对应差异值。还可查看历史时间安排、依赖清单及当前成员剩余工作量。图表使用持久化数据；工作量不是成员贡献评分，任务完成比例不代表功能验收。
12. 在“阶段成果”左侧选择阶段和提交版本，右侧查看该版本的材料、计划版本、当时进度和教师意见。切换旧版本不会改写当前阶段状态。学生可上传团队附件；组长填说明和成果链接、勾选附件，并为每项交付物选择材料。无需手工输入内部文件 ID。多项交付物必须逐项映射；每次提交新建版本，保留旧材料、计划版本、进度快照和教师意见。

## 手机与键盘操作

窄屏顶部“打开导航菜单”展开菜单，选择页面或按 Escape 关闭并返回入口。任务看板提供“全部、待开始、进行中、已完成”筛选，搜索和“只看本人任务”仍可同时使用。

团队协作在手机上通过“讨论”和“建议与草案”切换。点击建议的来源会切回讨论并定位消息；回复追问也会切回讨论、关联卡片并聚焦输入框，保留已输入内容。计划比较按任务展示变更前后记录，排期按任务显示日期区间。

任务抽屉在手机上使用全宽布局。菜单与弹窗支持 Tab 焦点环绕和 Escape 关闭，关闭后恢复入口焦点。上述行为已有组件测试和源码审查；新版界面的实际手机浏览器验收尚未完成，详见测试记录。

## 教师操作路径

1. 从工作台进入“课程要求”创建或编辑本人课程。填写课程名称、项目说明、课程验收标准、功能列表、参考链接，以及三个阶段的名称、截止日期和交付物；无需填写 JSON。
2. 新课程可保存草稿。发布须具有说明、非空验收标准、必做功能、三个阶段和每阶段交付物，阶段日期须严格递增。已发布课程可修改或归档，不能退回草稿。输入或状态冲突会保留表单并显示实际原因。
3. 进入自己课程下项目，查看任务完成比例、当前规划检查、已确认需求、只读任务详情、已发布计划快照和阶段提交。停留“已确认需求”时，顶栏“刷新数据”会同时更新当前已确认需求。
4. 在“阶段成果”查看每次提交的材料与历史快照，下载已提交附件，选择“通过”或“需要修改”并填写检查意见。审核结果不会自动把开发任务标为完成。

教师导航没有聊天室、内部卡片和运行记录入口。基础项目加载不请求 messages/cards/runs/comments 或内部文件目录；需求页只读取服务端过滤后的已确认需求。教师附件名通过本项目阶段提交中的文件引用逐项取得，下载仍由服务端校验权限。

## 错误与数据一致性

列表请求失败会显示对应资源的中文错误，不把失败伪装成空列表。字段校验显示字段及实际消息，规划冲突显示服务端 violations、关联任务与计算口径。保存和提交按钮具有等待状态，失败后保留表单输入。当前任务和进度风险使用服务端实时检查；历史计划与阶段提交仍展示当时快照。

切换项目会销毁旧连接、清空旧项目状态，并利用请求代次拒绝迟到数据。HTTP 发送结果与实时广播按消息 ID 合并。附件下载使用 Bearer fetch 后生成 blob，不把令牌加入外部链接或普通附件链接。消息正文采用文本渲染。

## 验证范围与限制

行为测试覆盖请求失败传播、当前令牌、401 会话隔离、字段错误、消息去重与失败重试、卡片发布权限、本人任务权限、计划比较、项目切换迟到响应与连接数、教师加载边界、退出后的身份恢复以及最小任务 PATCH、成员任务依据显示、迟到的项目创建与分析请求，以及断线期间 HTTP 新消息之前的历史空洞补齐。新版还增加了本人工作台、最新阶段提醒、菜单与弹窗焦点、旧提交版本选择、材料逐项映射及教师审核历史的测试。生产构建验证 Vue 组件与资源打包。

行为测试与生产构建不能代替浏览器实际操作验收。真实模型调用质量与供应商兼容性需要配置服务端模型后单独验收；无配置时前端明确显示 503，不能据本地构建或受控行为测试推断真实模型可用。初版无自助注册、账号管理、自动加入项目和任务拖动功能；任务通过详情表单推进。

## 代码位置

`src/App.vue` 负责布局与导航，`src/workspace.js` 负责会话、请求代次和实时协作，`src/api.js` 负责鉴权请求及错误转换，`src/state.js` 提供合并、权限、计划比较和最小更新载荷，`src/workbench.js` 从当前项目数据派生本人工作台。`src/views/` 包含九个业务页面，`src/components/` 包含统一 SVG 图标、任务、草案、材料和可访问对话框组件，`src/style.css` 引入 `src/styles/` 的基础、工作区、协作、登录和响应式样式模块，提供桌面及窄屏布局。
