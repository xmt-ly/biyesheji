## 云端安装与启动建议

先在云端环境中选择私有仓库 `xmt-ly/biyesheji`。建议 Python 3.12、Node.js 24。先验证实际版本，再按锁文件安装；下面的命令应在仓库根目录运行并实际检查结果：

```bash
python3 --version
node --version
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
.venv/bin/python -m pip check
npm --prefix frontend ci
npm --prefix frontend test
npm --prefix frontend run build
```

云端首次启动使用新的独立数据目录和关闭的 AI，不导入本地业务库。仅供私有开发预览的演示数据可按以下命令显式初始化，重复执行会检查演示数据是否已存在：

```bash
export DATA_DIR="$PWD/data/cloud-demo"
export LLM_API_KEY=''
export LLM_MODEL=''
PYTHONPATH=backend .venv/bin/python -m app.seed
.venv/bin/python -m uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8000
```

由云端平台提供私有预览入口，并验证首页、静态资源、登录、权限与阶段流程；实际网址由平台返回，不能把 `127.0.0.1` 写成互联网部署地址。服务启动不等于生产托管、业务数据迁移或 AI 质量验收完成。

后端及各离线实验应使用独立测试 `DATA_DIR`、测试专用 JWT 和空模型配置。原 `scripts/Test.ps1` 以及部分脚本测试依赖 Windows PowerShell，Linux 环境需要逐项核对可执行性；无法运行的项明确记录原因，不无声跳过或改成通过。
