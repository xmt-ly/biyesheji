# 图源说明

全部 `.mmd` 文件是根据当前实现绘制的系统示意图，不是界面截图。论文正式排版可渲染为 SVG 或 PNG，保持原始源文件便于修改。

| 文件 | 对应图题 | 阅读边界 |
| --- | --- | --- |
| 图4-1-系统架构.mmd | 系统总体架构 | 持久意图在 SQLite 中，图中独立方框表示逻辑职责 |
| 图4-2-核心实体关系.mmd | 核心实体及主要关系 | 15 个实体对应 15 张物理表；仅画主要外键；JSON 来源、依赖与材料关系不另造关联表 |
| 图4-3-Agent处理与恢复.mmd | 有界分析与检查点恢复 | 60 秒是模型交互循环默认预算，不含聚合和所有端到端步骤；失败不自动无限重试 |
| 图5-1-草案发布时序.mmd | 草案核对与发布 | 成员反馈不等于强制全员签署；服务端最终校验组长权限与完整约束 |
| 图5-2-三阶段交付流程.mmd | 三阶段业务主线 | 箭头表达推荐主线；接口未强制前阶段通过才允许后阶段提交，也未自动归档 |

第 4 章已嵌入架构 Mermaid，其他图在对应说明处引用源文件。学校正式模板可能需要统一图中文字、字体和编号。新版桌面与 390 px 手机实际操作验收尚未完成，不能以本目录图源或设计平台输出代替真实截图。
